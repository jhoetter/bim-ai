# Target House 2 Visual Readout

## Source Summary

The source package describes a traditional semi-detached residential building in
Dahlerbrueck / Schalksmuehle. The old approval drawings show the complete paired
double-house context; the current expose identifies one semi-detached half as
Weidenstrasse 6.

## Primary Geometry Read

- Full paired footprint: 19.80 m wide by 8.75 m deep.
- One semi-detached half: 9.90 m wide by 8.75 m deep.
- Building has basement, Erdgeschoss, Dachgeschoss, and a continuous pitched
  tiled roof.
- The plan is mirrored around a central party/stair zone.
- Long elevations show paired front doors, smaller ground-floor windows, larger
  upper/dormer window groupings, tiled roof overhangs, and gable end walls.
- Section shows basement below grade, main floor, stair up to the roof storey,
  and a steep pitched roof with attic volume.

## Room/Area Read

`Wohnflaechenberechnung.pdf` lists one half as:

- EG: Wohnzimmer 18.65 m2, Schlafzimmer 16.69 m2, Flur 5.37 m2,
  Kinderzimmer 9.33 m2, Kueche 6.47 m2, Speisekammer 0.52 m2,
  Bad u.W.C. 4.58 m2, total 61.61 m2.
- DG: Wohnzimmer 15.66 m2, Schlafzimmer 15.33 m2, Flur 5.37 m2,
  Kinderzimmer 7.68 m2, Kueche 5.70 m2, Bad u.W.C. 4.68 m2,
  total 54.42 m2.
- One half total: 116.03 m2.
- Full paired building total: 232.06 m2.

`Umbauter Raum.pdf` lists one half as 86.625 m2 built area and 660.88 m3
enclosed volume; full paired context is 173.25 m2 and 1321.76 m3.

## Seed Interpretation

The initial seed models the complete paired context so the 19.80 m source
dimension and mirrored plan logic remain visible. It keeps Weidenstrasse 6 as a
source/provenance label rather than cropping away the paired context. This avoids
creating a half-building that no longer matches the original approval drawings.

## Deferred Detail

- Exact historic masonry wall jogs and facade ornament are deferred.
- Exact dormer carpentry is represented with roof-hosted dormer proxies.
- Parcel/legal/drainage/energy details are source-provenance only in the initial
  BIM seed, except for starter site and property-line context.
- Live Advisor/constructability evidence has not yet been generated for this
  artifact.
